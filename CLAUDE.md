# Project rulebook

## Repo layout
- **Working directory:** `proposed_center/` — this is where all edits happen. The Next.js 16 app specifically lives in `proposed_center/site/` (which has its own scoped rules in `site/AGENTS.md`).
- **Read-only reference:** `tmdl_archive/` — never edit, move, or delete anything inside this directory. It is archived reference material from the prior version of the site.

## Project context
For project background, current state, and past decisions, read these files at the repo root:
- `PROJECT_BRIEF.md` — what this project is and why
- `STATE.md` — current state of the work
- `DECISIONS.md` — record of past architectural / content decisions

Don't duplicate this content into responses; refer to it as needed.

## Git
- Commits are fine to make when explicitly asked.
- **Never `git push` without explicit confirmation in the current turn.** Past approval doesn't carry forward to a new push.
- Remote: `github.com/pranish-k/new-center`.
